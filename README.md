# Юридическая фирма «Монолит» — сайт

Редизайн сайта monolit-advokat.ru (Новосибирск) на Node.js + Express + SQLite,
с калькулятором примерной стоимости, каталогом реальных судебных решений,
образцами договоров и админ-панелью.

## Стек

- Express (сервер, роуты, API)
- better-sqlite3 (БД, режим WAL)
- express-session + bcryptjs (авторизация админа)
- express-rate-limit (защита от подбора пароля)
- helmet (security headers, CSP)

## Что нового относительно оригинала

Оригинал был чисто информационным сайтом без единой формы обратной связи и без
интерактивного расчёта — только телефон/почта текстом. На редизайне добавлено:

1. **Форма заявки на каждой странице** (`/api/leads`) — раньше сайт не давал
   написать напрямую, только звонить/писать на email.
2. **Калькулятор примерной стоимости** (`/kalkulyator`) — выбор услуги из полного
   прайс-листа со сразу видимой ценой, вместо пролистывания таблиц.
3. **Админ-панель** — весь контент (прайс-лист, настройки, заявки) редактируется
   без правки кода, у оригинала такой возможности не было видно публично.

## Локальный запуск

```
npm install
npm run seed    # создаёт БД, наполняет реальными данными с оригинала, создаёт админа
npm start       # http://localhost:3500
```

Админ-панель: http://localhost:3500/admin — логин/пароль по умолчанию `admin` / `monolit2026`
(указаны в `.env.example`, обязательно смените перед реальным использованием).

## Перед деплоем — обязательно

1. Скопировать `.env.example` в `.env`, задать реальный `SESSION_SECRET` (длинная случайная строка).
2. Сменить пароль администратора через админ-панель.
3. Заменить `ЗАМЕНИТЕ-НА-ДОМЕН.ru` на реальный домен во всех `<link rel="canonical">`,
   `og:image`, `robots.txt`, `sitemap.xml` (когда домен появится).
4. **Заполнить реквизиты юрлица** (ИНН/ОГРН/КПП) в `public/privacy.html` — они не
   были опубликованы на исходном сайте и не найдены в открытых реестрах по имеющимся
   данным, сейчас там плейсхолдер `[заполнить]`.

## Деплой на PaaS (Render и подобные)

1. Создать новый Web Service, подключить репозиторий.
2. Build command: `npm install`
3. Start command: `npm run seed && npm start` (seed идемпотентен — безопасно запускать
   при каждом деплое, данные не задвоятся)
4. Задать переменные окружения (`SESSION_SECRET`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`,
   `NODE_ENV=production`) в панели хостинга.
5. **Важно**: SQLite-файл должен жить на постоянном (не эфемерном) диске — на части
   бесплатных тарифов PaaS файловая система сбрасывается при каждом деплое.

## Деплой на VPS

1. Установить Node.js, склонировать репозиторий, `npm install`, `npm run seed`.
2. Установить PM2 (`npm install -g pm2`), запустить `pm2 start ecosystem.config.js`.
3. `pm2 save && pm2 startup` — чтобы сайт поднимался сам после перезагрузки сервера.
4. Настроить nginx как реверс-прокси на порт из `.env` (`PORT`), выпустить HTTPS-сертификат
   (Let's Encrypt/certbot).

## Резервное копирование

`npm run backup` — создаёт снапшот БД в `data/backups/` (хранит последние 14 копий).
Поставьте эту команду в cron на хостинге (например, раз в сутки).

Восстановление: остановить сервер → удалить `*.db-wal`/`*.db-shm` → скопировать нужный
файл из `data/backups/` поверх `data/monolit.db` → запустить сервер заново.
